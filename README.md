# Учебный frontend-проект

## Описание

Проект выполняется в рамках дисциплины «Фронтенд и бэкенд разработка».

Тема проекта: многостраничный сайт интернет-магазина или каталога услуг.

## Структура проекта

- `index.html` — главная страница с отзывами и FAQ;
- `catalog.html` — расширенный каталог: 10 товаров в трёх категориях, sticky-фильтр, таблица сравнения;
- `category-audio.html`, `category-gadgets.html`, `category-computers.html` — страницы категорий;
- `product.html` — подробная карточка товара (беспроводные наушники) с характеристиками;
- `product-*.html` — страницы остальных 9 товаров по тому же шаблону (`product-smartwatch.html`,
  `product-speaker.html` и т.д.);
- `contacts.html` — контактная информация;
- `css/style.css` — файл стилей;
- `js/main.js` — скрипты страницы;
- `images/` — фотографии товаров (JPEG 800×600) и баннеры категорий (900×600);
- `sitemap.xml` — простая карта сайта;
- `.gitignore` — список файлов, исключённых из Git;
- `README.md` — описание проекта.

## Самостоятельные доработки

### Расширенный каталог

- 10 товаров в трёх категориях: «Аудио», «Гаджеты», «Компьютеры»;
- навигация по категориям `category-nav` со счётчиками товаров, каждая категория ведёт
  на свою страницу;
- панель `catalog-toolbar` с количеством найденных товаров и сортировкой;
- товары сгруппированы по категориям в блоки `catalog-group`;
- фильтры расширены: категория, наличие, цена, особенности (хиты, новинки, скидки), кнопка «Сбросить»;
- карточки получили новые элементы и модификаторы:
  - `product-card__stock--available` / `product-card__stock--order` — в наличии или под заказ;
  - `product-card__badge--new` / `product-card__badge--sale` — метки «Новинка» и скидка;
  - `product-card__price-old` — зачёркнутая старая цена (для экранного диктора подписана «Старая цена»);
  - `product-card__category` — подпись категории в карточке на главной;
  - `product-card__actions` — кнопки «Подробнее» и «Заказать», прижатые к низу карточки;
- у каждого товара своя страница: «Подробнее» есть во всех карточках на главной, в каталоге
  и в категории. Страницы собраны по одному шаблону `product-details`, отличаются данными:
  фото, описание, характеристики, метки и наличие (модификаторы `product-details__badge--new`,
  `product-details__badge--sale`, `product-details__stock--order`).

Фильтры и сортировка оформлены как статическая разметка: КР №1 — HTML/CSS-проект,
поэтому реальная фильтрация на JavaScript не делалась.

### Страница отдельной категории

У каждой категории своя страница: `category-audio.html`, `category-gadgets.html`,
`category-computers.html`. Страницы построены по одному шаблону и отличаются данными:

- хлебные крошки «Главная / Каталог / Аудио», на странице товара — «… / Аудио / Беспроводные наушники»;
- первый экран `category-hero`: описание, ключевые факты и фото, раскладка на CSS Grid;
- свои фильтры для каждой категории: например, у «Аудио» — тип устройства и подключение,
  у «Гаджетов» — тип и возможности (GPS, NFC, защита от воды);
- в навигации `category-nav` текущая категория выделена модификатором `category-nav__link--active`;
- блок советов `tips` по выбору товаров этой категории.

### Улучшенное модальное окно

- шапка окна с заголовком и кнопкой-крестиком `order-dialog__close` (`aria-label="Закрыть окно"`);
- шапка закреплена через `position: sticky` и `z-index`, длинная форма прокручивается внутри окна,
  высота окна ограничена `max-height: calc(100vh - 32px)`;
- в окне показывается выбранный товар: фото, название и цена берутся из `data-product`,
  `data-price`, `data-image` кнопки «Заказать»;
- тема заявки «Заказ товара» выбирается автоматически;
- закрытие по крестику, кнопке «Отмена», клавише Esc и клику по затемнённому фону;
- при закрытии форма очищается вместе с подсветкой ошибок;
- обязательные поля отмечены звёздочкой, подсказка телефона связана с полем через `aria-describedby`;
- после отправки вместо формы появляется сообщение об успехе, фокус переходит на кнопку «Готово»;
- плавное появление окна и затемнения через `@keyframes`, отключается при `prefers-reduced-motion`;
- страница под открытым окном не прокручивается: `body:has(.order-dialog[open]) { overflow: hidden; }`;
- окно работает на главной, в каталоге, на странице категории и на странице товара.

### Sticky-фильтр каталога

```css
.catalog-filters {
  position: sticky;
  top: var(--space-md);
  align-self: start;
  max-height: calc(100vh - 2 * var(--space-md));
  overflow-y: auto;
}
```

- фильтр остаётся на экране, пока прокручивается список товаров;
- `align-self: start` нужен, потому что по умолчанию ячейка Grid растягивает фильтр
  на всю высоту строки и ему некуда «прилипать»;
- если фильтр выше окна, он прокручивается сам;
- на экранах уже 768px раскладка становится одной колонкой, а фильтр — обычным блоком
  (`position: static`), чтобы не перекрывать карточки.

### Работа с изображениями

- SVG-заглушки заменены на фотографии товаров (JPEG 800×600, около 30–100 КБ каждая);
- у `img` указаны `width` и `height`, поэтому место под фото резервируется до загрузки;
- `aspect-ratio: 4 / 3` и `object-fit: cover` — фото одного размера без искажения пропорций;
- `loading="lazy"` в каталоге — фото ниже первого экрана загружаются при прокрутке;
- у каждого фото содержательный `alt`.

## Вёрстка: Flexbox и CSS Grid

Flexbox используется там, где элементы выстраиваются в одну линию:

- `.site-header__inner` — логотип и меню по краям шапки;
- `.site-nav__list` — пункты меню в строку: `display: flex`, `flex-wrap: wrap`,
  `justify-content: center`, `align-items: center`, `gap`;
- `.site-footer__inner` — две строки подвала по краям;
- `.product-card` — вертикальная колонка с `gap`, блок кнопок `.product-card__actions` прижат к низу через `margin-top: auto`;
- `.category-nav__list`, `.catalog-toolbar`, `.catalog-group__header` — строки с переносом на узком экране;
- `.order-dialog__header`, `.order-dialog__product` — шапка окна и выбранный товар;
- `.order-form__actions` — кнопки формы в строку.

CSS Grid используется для сеток:

- `.products-grid` — сетка карточек товаров на главной и в каталоге,
  `grid-template-columns: repeat(auto-fit, minmax(240px, 1fr))`;
- `.catalog-layout` — раскладка каталога `grid-template-columns: 260px 1fr`
  и `grid-template-areas: "filters products"`, блоки занимают области через `grid-area`;
- `.catalog-filters__form` — группы фильтров друг под другом с одинаковым `gap`;
- `.category-hero` — текст и фото категории в две колонки;
- `.tips` — карточки советов на странице категории.

- `hero` — первый экран главной страницы;
- `section` — раздел страницы;
- `products-grid` — сетка товаров;
- `product-card` — карточка товара;
- `catalog-layout` — структура страницы каталога;
- `catalog-filters` — фильтры каталога;
- `catalog-products` — список товаров в каталоге;
- `category-nav` — навигация по категориям каталога;
- `catalog-toolbar` — панель с количеством товаров и сортировкой;
- `catalog-group` — группа товаров одной категории;
- `category-hero` — первый экран страницы категории;
- `tips` — советы по выбору на странице категории;
- `visually-hidden` — текст только для экранных дикторов;

## Позиционирование элементов

- `position: relative` — `.product-card`, задаёт систему координат для метки внутри карточки;
- `position: absolute` — `.product-card__badge`, метка «Хит» в правом верхнем углу карточки;
- `position: fixed` — `.to-top`, кнопка «Наверх» остаётся в углу окна при прокрутке;
- `position: sticky` — `.catalog-filters`, фильтр каталога «прилипает» к верху окна,
  и `.order-dialog__header`, шапка модального окна при прокрутке формы;
- `z-index` — метка на карточке поверх фото и шапка окна поверх полей формы.

## Навигация и якорные ссылки

Одинаковое меню стоит на всех страницах сайта. Кроме переходов на `index.html`,
`catalog.html` и `contacts.html` в нём есть якорные ссылки на разделы главной
страницы: `index.html#advantages`, `index.html#popular`, `index.html#contacts`.

Якорь работает, когда значение `href="#id"` совпадает с атрибутом `id` раздела.
Переход сделан плавным через `scroll-behavior: smooth`, а нужный раздел
подсвечивается псевдоклассом `:target`.

На страницах каталога, товара и контактов есть хлебные крошки: ссылки на
вышестоящие страницы и название текущей страницы (`breadcrumbs__current`), которое не является ссылкой.
