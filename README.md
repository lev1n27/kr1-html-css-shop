## Вёрстка: Flexbox и CSS Grid

Flexbox используется там, где элементы выстраиваются в одну линию:

- `.site-header__inner` — логотип и меню по краям шапки;
- `.site-nav__list` — пункты меню в строку с переносом на узком экране;
- `.site-footer__inner` — две строки подвала по краям;
- `.product-card` — вертикальная колонка, кнопка прижата к низу карточки;
- `.form-actions` — кнопки формы в строку.

CSS Grid используется для сетки товаров:

- `.product-list` — `grid-template-columns: repeat(auto-fit, minmax(260px, 1fr))`,
  количество колонок меняется автоматически по ширине окна.

## БЭМ-именование классов

Блок — независимый компонент, элемент — его часть после `__`:

- `.product-card`, `.product-card__img`, `.product-card__title`, `.product-card__price`,
  `.product-card__text`, `.product-card__button`, `.product-card__badge`;
- `.site-header`, `.site-header__inner`, `.site-header__logo`;
- `.site-nav`, `.site-nav__list`, `.site-nav__item`, `.site-nav__link`;
- `.site-footer`, `.site-footer__inner`, `.site-footer__text`.

## Позиционирование элементов

- `position: relative` — `.product-card`, задаёт систему координат для метки внутри карточки;
- `position: absolute` — `.product-card__badge`, метка «Хит» в правом верхнем углу карточки;
- `position: fixed` — `.to-top`, кнопка «Наверх» остаётся в углу окна при прокрутке.

## CSS-архитектура

В проекте используются:

- CSS-переменные в `:root`;
- единая шкала отступов;
- переменные для цветов и скруглений;
- состояния `:hover`, `:focus-visible`, `:disabled`;
- визуальная подсветка ошибочных полей через `aria-invalid`;
- структурированный файл `css/style.css`.

Файл `css/style.css` разделён на блоки:

1. переменные проекта;
2. базовые стили;
3. общие элементы интерфейса;
4. компоненты страницы;
5. форма и модальное окно.
